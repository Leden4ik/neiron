# Нейрон Фомич

Лендинг ИИ-напарника для Системы Охрана труда, сверстан по макету из Figma (фрейм "Нейро вариант 1").
Сборка та же, что у меня в других проектах: Gulp, Pug для разметки, SCSS для стилей, esbuild для скриптов.
Библиотек нет, всё на чистом js.

## Как запустить

Нужен Node 18+ (версия лежит в `.nvmrc`).

```bash
npm install
npm run dev      # локальный сервер на http://localhost:3000
npm run build    # чистая сборка в dist/
npm run zip      # архив с готовой версткой
```

## Где что лежит

Правится всё в `src/`, папку `dist/` руками не трогаю, она пересобирается.

```
src/
  tmp/
    index.pug            страница, тут просто подключаются секции по порядку
    _config/data.pug     весь контент: вопросы в первом экране, демо-чат, эксперты,
                         темы с ответами, цифры, таблица тарифов
    _config/helper.pug   миксины: иконка, кнопка, пузыри чата, аватар
    module/header        верхняя полоска Актиона
    module/footer        подвал
    module/sections      секции страницы, каждая в своем файле
  scss/
    config/              переменные, миксины, брейкпоинты, шрифты
    main/style.scss      база: контейнер, заголовки, лид
    layout/              header.scss (там же первый экран и меню), footer.scss
    module/button        кнопки и плашки
    module/chat          пузыри и окна чата, они повторяются почти во всех блоках
    module/sections      demo.scss, pricing.scss и sections.scss для остальных блоков
  js/modules/            nav, demo, topics, counter, form
  icons/                 svg-иконки, из них собирается спрайт
  img/                   логотипы, фото Фомича и экспертов
```

## Что на странице работает

- Меню под первым экраном прилипает к верху и подсвечивает раздел, в котором сейчас находишься.
- Демо-чат проигрывается сам, когда до него доскроллили: вопрос печатается, отправляется, Фомич "думает" и отвечает. Кнопка "Новый вопрос" запускает заново.
- В блоке "Знаю все участки" по клику на тему меняется вопрос и ответ в чате. Повторный клик по активной теме возвращает пример по умолчанию.
- Цифры смены набегают при появлении блока.
- Форма с маской телефона и проверкой полей. Отправки на сервер пока нет, после проверки просто показывается сообщение. Место для запроса помечено в `js/modules/form.js`.

## Что важно знать

- Классы с префиксом `nf__`, схема `nf__блок--элемент`, состояния через `is-active`, хуки для js начинаются с `js--`.
- Размеры пишу в px как в макете, pxtorem при сборке переводит их в rem.
- Шрифт в макете Proxima Nova. У меня нашелся только Regular, поэтому полужирный и жирный пока рисует браузер. Когда будут файлы, кладу `ProximaNova-Semibold.woff2` и `ProximaNova-Bold.woff2` в `src/fonts/` и дописываю для них два блока `@font-face` в `src/scss/config/fonts.scss` (вес 600 и 700, имя семейства то же, `Proxima Nova`). Заголовки тогда переносятся точно как в макете.
- Рукописная подпись в первом экране выгружена из макета в svg, отдельный шрифт ради нее не нужен.
- Мобильной версии в макете не было, адаптив делал сам. Брейкпоинты: до 769px мобилка, до 1024px планшет, от 1216px десктоп с контейнером 1128px.
- Таблица тарифов на узких экранах скроллится вбок, первая колонка при этом стоит на месте.
